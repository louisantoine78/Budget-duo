# Trace V4 — changelog

## Interface
- Nouveau nom Trace.
- Responsive iPhone réécrit.
- Formulaires sans zoom automatique.
- Budget sous forme de cartes.
- Table des transactions transformée en cartes sur mobile.

## Budget et analyse
- Suppression de la vue principale « Dépenses communes ».
- Projection : réel + récurrences restantes + tendance des dépenses variables.
- Flux net du mois clairement distingué du solde bancaire.
- Solde de départ facultatif et position estimée.

## Transactions
- Payeur par défaut selon le compte Supabase connecté.
- Date locale automatique.
- Paiement à une personne.
- Remboursement reçu d’une personne.
- Dépenses avec participants extérieurs.
- Récurrences complètes.

## Données
- Migration additive.
