# Installation rapide de la synchronisation

1. Crée un projet Supabase.
2. Exécute `supabase-schema.sql` dans **SQL Editor**.
3. Copie le **Project URL** et la clé **Publishable/anon** dans `config.js`.
4. Dans **Authentication → URL Configuration**, ajoute ton adresse GitHub Pages comme Site URL et Redirect URL.
5. Remplace les fichiers de la V2 dans GitHub par ceux de la V3.
6. Ouvre l’application, crée ton compte et ton espace.
7. Copie le lien d’invitation dans **Paramètres** et envoie-le à Élise.
8. Élise crée son propre compte et rejoint l’espace avec le code prérempli.

Ne mets jamais la clé `service_role` dans `config.js`.
