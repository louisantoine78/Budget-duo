# Mise à jour Trace V4.1

1. Conserver la sauvegarde JSON déjà téléchargée.
2. Ne rien exécuter dans Supabase : aucune migration SQL n’est nécessaire.
3. Dans GitHub, téléverser le contenu de ce dossier à la racine du dépôt Budget-duo.
4. Ne pas remplacer ni supprimer le fichier config.js déjà présent sur GitHub.
5. Commit direct sur main avec le message `Correctifs Trace V4.1`.
6. Attendre que GitHub Actions / pages build and deployment soit vert.
7. Ouvrir Trace sur Safari, actualiser, puis rouvrir l’app depuis l’écran d’accueil.
8. Accepter la mise à jour si le bandeau apparaît.

Les transactions, budgets et catégories existants sont conservés dans Supabase.
